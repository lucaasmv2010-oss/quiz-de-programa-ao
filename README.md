# quiz-de-programa-ao

Quiz Interativo de Programação
O Quiz Interativo de Programação é um projeto desenvolvido durante meus estudos de HTML, CSS e JavaScript, criado para praticar lógica de programação de forma mais aplicada.
A aplicação apresenta perguntas de múltipla escolha sobre conceitos de programação, identifica a alternativa selecionada, verifica se a resposta está correta, controla a pontuação, avança entre as perguntas e exibe o resultado final.
Durante o desenvolvimento, estou reforçando conceitos que já apareceram em projetos anteriores, principalmente arrays, objetos, índices, funções, condicionais, eventos e manipulação do DOM. Também estou aprendendo melhor como controlar o estado de uma aplicação, utilizando variáveis para saber qual pergunta está sendo exibida e quantos pontos o usuário possui.
Este projeto é especialmente importante para minha evolução porque estou tentando depender menos de código pronto. Em várias etapas, primeiro entendo o problema, tento construir a solução sozinho, identifico meus erros e depois faço as correções necessárias.
Tecnologias: HTML5, CSS3 e JavaScript.
Principais conceitos praticados: arrays de objetos, índices, forEach(), if/else, funções, addEventListener(), criação dinâmica de elementos, classList, controle de estado e lógica de pontuação.
